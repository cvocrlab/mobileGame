# 🚀 우주선 피하기 (Space Dodger)

HTML5 Canvas와 순수 JavaScript로 제작된 모바일 최적화 아케이드 게임입니다. 
별이 흐르는 우주를 배경으로, 떨어지는 운석을 피하며 자신의 한계 점수를 도전해 보세요!

## 🎮 게임 특징
- **완벽한 모바일 지원:** 터치 및 드래그에 최적화된 조작계
- **반응형 디자인:** 스마트폰, 태블릿, PC 등 모든 화면 크기에 자동 적응
- **동적 난이도:** 점수가 높아질수록 운석의 속도와 빈도가 증가
- **경량화된 코드:** 외부 라이브러리 없이 순수 HTML/CSS/JS로만 구성 (빌드 과정 불필요)

## 🕹️ 조작 방법
| 환경 | 조작법 |
| :--- | :--- |
| **모바일** | 화면을 터치하거나 드래그하여 우주선 이동 |
| **PC** | 마우스를 움직여 우주선 이동 |

*게임 오버 후 화면을 터치(또는 클릭)하면 즉시 재시작됩니다.*

## 🚀 실행 방법 (설치 불필요)
이 게임은 별도의 서버나 빌드 과정 없이 웹 브라우저만 있으면 바로 실행할 수 있습니다.

### PC에서 실행하기
1. 이 저장소의 코드를 다운로드하거나 복사합니다.
2. 메모장이나 VS Code 등의 텍스트 편집기를 엽니다.
3. 코드를 붙여넣고 파일명을 `game.html`로 지정하여 저장합니다.
4. `game.html` 파일을 더블클릭하여 기본 웹 브라우저(Chrome, Edge, Safari 등)로 실행합니다.

### 모바일에서 실행하기
1. PC에서 `game.html` 파일을 카카오톡, 이메일, 또는 클라우드(Google Drive 등)를 통해 스마트폰으로 전송합니다.
2. 스마트폰의 파일 관리자에서 `game.html`을 선택하여 브라우저로 엽니다.
3. *(선택 사항)* 전체화면으로 플레이하려면 브라우저의 '홈 화면에 추가' 기능을 사용하면 앱처럼 사용할 수 있습니다.

## 🛠️ 기술 스택
- **Frontend:** HTML5, CSS3
- **Logic:** Vanilla JavaScript (ES6+)
- **Rendering:** HTML5 `<canvas>` API

## ⚙️ 커스터마이징 가이드
코드를 직접 수정하여 나만의 게임으로 만들어 보세요! (`<script>` 태그 내부)

- **난이도 조절:** `spawnAsteroid()` 함수 내의 `speed` 값을 수정하면 운석의 속도를 변경할 수 있습니다.
- **생성 빈도:** `update()` 함수 내의 `if (frameCount % 20 === 0)` 부분의 숫자를 줄이면 운석이 더 자주 쏟아집니다.
- **색상 변경:** `draw()` 함수 내의 `ctx.fillStyle` 값을 변경하여 우주선(`#00ffcc`)이나 운석(`#ff4444`)의 색상을 바꿀 수 있습니다.
- **배경 별 개수:** `for (let i = 0; i < 50; i++)` 부분의 `50`을 조절하여 별의 밀도를 조정할 수 있습니다.
